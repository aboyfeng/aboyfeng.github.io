This site is a static site generated by [Hugo](https://gohugo.io/), styled with
the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme, and
published to GitHub Pages by a GitHub Actions workflow.

## The stack

| Layer | Choice |
| --- | --- |
| Generator | Hugo (extended) |
| Theme | PaperMod |
| Hosting | GitHub Pages |
| CI/CD | GitHub Actions |
| Content | Markdown in git |

## Writing a post

```bash
# scaffold a new post
hugo new content posts/my-new-post.md

# preview with drafts and live reload
hugo server -D
```

Front matter is plain TOML/YAML; PaperMod picks up `title`, `date`, `tags`,
`categories`, `summary`, `showToc` and friends.

## Publishing

Every push to `main` triggers the workflow:

1. Install the pinned Hugo extended release.
2. Check out the repository, including the theme submodule.
3. Run `hugo --gc --minify`.
4. Upload `public/` as a Pages artifact and deploy it.

Nothing is built locally for deployment, so publishing a post is just
`git push`.

## Why this setup

- **Fast** — a static site with no server, no database, no build step at
  request time.
- **Portable** — content is plain Markdown in a git repository.
- **Free** — GitHub Pages hosts it, GitHub Actions builds it.
- **Boring** — which, for a blog, is exactly what you want.
