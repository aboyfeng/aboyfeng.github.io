欢迎。这是本站的第一篇文章，主要是让首页看起来不那么空，顺便把整套模板从头到尾走一遍。

## 这是什么

一个私人笔记本。文章会尽量短、尽量具体，首先是写给我未来的自己看的——关于软件、系统、工具，以及其他当时觉得值得记下来的东西。

## 会写什么

- 以技术笔记为主，偶尔也写点别的。
- 没有固定更新节奏，有话可说的时候才会发文。
- 全部用纯 Markdown 写成，交给 git 管理版本，由 GitHub Actions 自动发布。
